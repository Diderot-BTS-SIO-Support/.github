# Page des liens classroom

Pour chaque devoir, un dépôt est créé, et il est nommé en respectant toujours la forme
### nomDuTP- + initiale du prénom + Nom

par exemple tp1-PremiersPasAvecGitHub-bObama

2 - Architecture d'un ordinateur : tp2-ArchitectureOrdinateurs

3 - Système d'exploitation Windows : tp3-SystemeDExploitationWindows
